
# Black Jack 

Juego web de Blackjack donde el usuario compite contra la computadora. Diseñado para practicar JavaScript, lógica de juego y manejo dinámico del DOM.


## Características principales

- Baraja de cartas completa con valores reales.
- Interfaz visual con cartas en pantalla.
- Botones para pedir carta, detenerse y reiniciar.
- Cálculo automático de puntos y ganador.
- Rápido de cargar y fácil de jugar.

## Tecnologías usadas

- HTML: Estructura del juego
- CSS Estilos: visuales del tablero y las cartas
- JavaScript:  Lógica del Blackjack y eventos del usuario
- Underscore.js: Apoyo en operaciones con arrays y barajas

## Instalación y ejecución

  1. Descarga o clona este repositorio:
```bash
  git clone https://github.com/usuario/blackjack.git
```

  2. Entra a la carpeta del proyecto:
```bash
  cd blackjack
```

  3. Abre el archivo:
```bash
  assets/index.html
```

## Ejemplo de uso

Botones del juego:

- Pedir carta → añade una carta a tu mano
- Detener → le toca jugar al computador
- Nuevo juego → reinicia el tablero

## Estructura del juego 

```txt
assets/
├─ cartas/          → Imágenes de cada carta
├─ css/             → Estilos del juego
├─ js/
│  ├─ juego.js      → Lógica principal del Blackjack
│  ├─ juego-min.js  → Versión minificada
│  └─ underscore-min.js → Librería de ayuda
└─ index.html       → Punto de entrada del juego
```
